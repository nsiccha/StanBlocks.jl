# Sandbox Gallery

The StanBlocks **sandbox** is a directory of one-file SLIC snippets,
each an `@slic` block (or a `@deffun` + `@slic` pair) that exercises a
specific feature: closures, kwargs, ragged vectors, ODE solvers, etc.
Each card shows the snippet's Julia source and its `stanc` status.
