# Development workbench

This application explores public PosteriorDB models and synthetic compiler
examples. It is separate from the documentation site. `app/main.jl` starts the
application using the `web/app` environment.

The Julia sources and expected diagnostics in `sandbox/` are inputs. Generated
`.stan`, `.stanc` and `.status` sidecars are local compilation products; the
sandbox's compile and compiler-check actions recreate them. The status files
under `status/` are likewise regenerated by the workbench. These files are
ignored by Git because they describe a particular run and can become stale
when the compiler changes.

Retain source, inputs and an execution receipt when recording a result. Keep
new recordings and generated assets outside the tracked source tree. The
current teaching examples and their reproduction instructions live in
[research](../research/README.md).
