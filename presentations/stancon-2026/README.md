# StanCon 2026 presentation

This directory preserves the dated conference presentation. It is outside the
current documentation site and its examples are historical, non-executed slide
snippets. Use the [current documentation](https://nsiccha.github.io/StanBlocks.jl/dev/)
for supported APIs and checked scientific examples.

Render the standalone deck with `quarto render index.qmd` from this directory.
The documentation build no longer installs Quarto or renders this deck. QR
images duplicated by the title fragment have been removed; the remaining
images are referenced by the presentation.
